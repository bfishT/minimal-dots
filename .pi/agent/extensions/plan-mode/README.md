# Enhanced Plan Mode

这是一个增强版 pi Plan 扩展，支持只读分析、结构化澄清问题、计划审批和结构化执行进度。

## 已启用的功能

- `/plan`：切换只读计划模式
- `/plan ask`：让模型重新检查并继续询问澄清问题
- `/plan execute`：执行当前计划
- `/todos`：查看计划进度
- `Ctrl+P`：切换计划模式（已释放内置的切换模型快捷键）
- `--plan`：启动时进入计划模式
- 计划阶段禁用 `edit`/`write`
- 计划阶段限制 Bash 为只读命令
- 模型可以调用 `questionnaire` 一次询问多个问题
- 每个问题支持选项和用户自定义回答
- 执行阶段通过 `plan_update` 工具更新步骤状态
- 计划状态保存在 pi session 中，支持恢复和分支

## 使用

`questionnaire.ts` 位于同级的全局扩展目录中，两个扩展都会自动加载。重新启动 pi，或执行：

```text
/reload
```

开始：

```text
/plan
```

然后让模型分析需求。遇到会影响实现的重要不确定性时，模型会打开 Questionnaire UI。用户提交答案后，模型会结合答案继续生成 Plan。

计划生成后可以选择：

- 执行计划
- 继续提问
- 手动修改计划
- 保持计划模式
- 取消计划

## 文件

- `index.ts`：Plan 状态机、工具权限、审批和执行流程
- `utils.ts`：计划提取和进度标记工具函数
- `../questionnaire.ts`：多问题交互工具
